# Changelog

## Unreleased

- Addons: install, open, control, update and remove separate apps from a new Addons tab

## 0.1.0 - 2026-11-01

First public version.

- Home screen with live stats, restart and shut down
- WiFi switching with automatic return to the previous network, and a hotspot fallback
- Network scanning and joining from the hotspot
- Preset file storage with uploads that never overwrite an existing file
- One-way phone backup through Syncthing, each phone in its own folder
- Video and audio downloads with yt-dlp, sorted into folders
- Read-only Tech tab with hardware, process, service, GPIO, device and log detail
- Installable web app with phone and desktop layouts, light and dark themes
